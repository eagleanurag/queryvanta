## Objective

## Scope

Phase 5 must not begin until task 4.2H passes. This task is design and
documentation only.

## Scope
1. Inspect the existing application and write a design document under `docs/`
   for anonymous product analytics.
2. Cover: what is measured, where events are collected, where they are stored,
   how they are aggregated, what the admin-facing view needs, and what the
   privacy position is.
3. State the free-tier cost model explicitly and quantitatively, using the
   Phase 4 findings as the baseline for what "cheap" means on this deployment.
4. Identify what must NOT be collected, and why, referencing the existing
   privacy posture in the repository.

## Non-goals
Do not implement collection, storage, or any UI. Do not add a dependency. Do not
add a schema. Do not collect any real data. Do not start this task until 4.2H has
passed; if it has not, report BLOCKED.

## Implementation requirements
The design must fit the existing architecture: Cloudflare Worker, D1, and a
server-enforced admin model. It must be consistent with the free-tier-first goal
and must not assume a paid tier. Prefer the smallest storage shape that answers
the questions the admin page would need. Be explicit about what is deliberately
not measured.
